# 站点协议（onetimeemail.com）

前端站点地址、注册/续期/收信接口、cookie 与凭证字段说明。

## 基础信息

- 站点：<https://onetimeemail.com>
- 所有接口走 HTTPS；登录态用 cookie 维持

## 主要接口（由 `app/services/client.py` 封装）

| 用途 | 方法 | 路径 |
|---|---|---|
| 创建邮箱 | POST | `/api/mailbox` |
| 查询邮箱信息 | GET | `/api/mailbox/{uuid}` |
| 续期（30 天） | POST | `/api/mailbox/{uuid}/renew` |
| 收件列表 | GET | `/api/mailbox/{uuid}/emails` |
| 邮件详情 | GET | `/api/mailbox/{uuid}/emails/{id}` |
| 删除邮箱 | DELETE | `/api/mailbox/{uuid}` |

> 具体字段以 `client.py` 实现为准；站点协议变更时只需改这一个文件。

## 凭证字段

| 字段 | 说明 |
|---|---|
| `uuid` | 邮箱唯一标识，站点接口的主要参数 |
| `recovery_phrase` | 助记词，可用于站点侧找回邮箱 |
| `cookies` | 登录态 cookie（PHPSESSID 等），导入已有账户时使用 |

字段全部保存在本地 SQLite 的 `mailboxes` 表，日志出口会脱敏展示。
